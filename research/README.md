# Research Catalog

Це папка для рісьорчів — питання що я (Sasha) досліджував з Claude, з висновками,
посиланнями і конкретними ідеями для цього проекту. Кожен файл — самостійний,
можна повертатись і тестити ідеї поетапно.

## Формат кожного файлу
- **TL;DR** — головна думка в 2-3 реченнях
- **Sources** — посилання на оригінальні матеріали
- **Notes** — "прожований" мною контент (детальні викладки)
- **Ideas to test** — конкретні дії для цього проекту з оцінкою impact/effort
- **Status** — `not tried` / `testing` / `applied` / `rejected`
